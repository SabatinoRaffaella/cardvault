# Client API reference

This mobile fork does not contain the server, database migrations or deployment scripts. The retained documents describe external API/authentication and wallet/card contracts useful to the client. They can cite historical implementation paths: consult the `v1.2.1` tag or `upstream` for those files.

Active mobile behavior and build commands are documented in `../README.md`, `../INSTALLATION.md` and `../docs/rebuild-*.md`. Do not execute historical server deployment commands from this fork.
